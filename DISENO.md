# Lineamientos del Proyecto

## Propósito

Repositorio de contenidos para estudiantes de **Metodología de la Educación a Distancia** y **Recursos Educativos Abiertos**.

## Estructura

- `index.html` — Página principal con listado de contenidos
- Pages adicionales según se requieran

## Principios de Diseño

- **Minimalista**: Solo elementos necesarios
- **Moderno**: Apariencia actualizada y limpia
- **Profesional**: Adecuado para formación docente
- **Centralizado**: Todas las páginas comparten mismo patrón visual

## Convenciones

| Aspecto | Convención |
|---------|------------|
| Nombres de archivos | minúsculas-con-guiones.html |
| Un solo H1 por página | Título principal |
| CSS | Archivo centralizado (`styles.css`) |
| Imágenes | Carpeta `/images/` |
| Links | Siempre incluir enlace de retorno al índice |

## Colores (referencia)

- Primary: `#1a237e` (azul oscuro educativo)
- Accent: `#e65100` (naranja llamadas de atención)
- Fondo: claro (`#fafafa`)

## Navegación

- Las páginas **no** enlazan al índice general
- Las páginas **no** enlazan a otros módulos
- Solo permiten navegación dentro del mismo módulo (páginas relacionadas entre sí)

## Mantenimiento

1. Toda página nueva debe seguir el mismo patrón visual
2. Mantener coherencia tipográfica y de espaciado
